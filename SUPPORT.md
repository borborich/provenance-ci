# Support

## Non-sensitive questions and bugs

Open a GitHub issue at
https://github.com/borborich/provenance-ci/issues. Include the tool version,
operating system, stable exit code, configuration with secrets and private paths
removed, and the smallest reproducible public or synthetic example.

Do not attach private media, signed URLs, credentials, tokens, full manifests,
EXIF/GPS data, certificates, or confidential JSON evidence.

## Security issues

Do not open a public issue. Use GitHub private vulnerability reporting:
https://github.com/borborich/provenance-ci/security/advisories/new.

## Scope

Support covers the current `0.1.x` local JPEG validator, CLI, and GitHub Action.
Remote manifests are not fetched or evaluated. Other media formats, signing,
hosted scanning, accounts, and service-level commitments are out of scope.
