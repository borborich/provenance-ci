# Provenance CI v0.1.0

This is the first public release of the local JPEG validation core, CLI, and
GitHub Action.

## Highlights

- Validates ordered local-path and hardened public-HTTPS JPEG checkpoints with
  the official Content Authenticity Initiative Rust SDK.
- Reports the first observed interval where credential presence, validation, or
  verifiable declared continuity changes.
- Keeps credential presence, cryptographic validation, explicit local trust,
  checkpoint relationship, and policy verdict separate.
- Produces versioned JSON evidence, Markdown summaries, GitHub annotations, and
  stable exit codes.
- Disables automatic remote-manifest and OCSP network retrieval.

## Release asset

The release includes a macOS Apple Silicon (`aarch64-apple-darwin`) archive and
a sibling SHA-256 file. Linux and other platforms can build from the immutable
tag with the committed `Cargo.lock`.

```text
ac2bd746ce8936dbf2cb865be24cd875ab443cbbacd4bc69c9a0c96d2e3ec343  provenance-ci-v0.1.0-aarch64-apple-darwin.tar.gz
```

## Important limits

Provenance metadata is not a truth, copyright, authorship, AI-detection, or
manipulation oracle. This release supports JPEG only. Remote manifests are not
fetched or evaluated. Trust is checked only when an explicit local PEM snapshot
is supplied. A changed file can be a valid declared derivative; the tool
reports only evidence available at the supplied checkpoints.

This project is not affiliated with or endorsed by C2PA, the Content
Authenticity Initiative, Adobe, or any other vendor. “Provenance CI” is a
working name only.
