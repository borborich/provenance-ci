# Provenance CI v0.1.1

This patch release prepares the local JPEG validator and GitHub Action for its
first GitHub Marketplace listing. The validation core, schemas, policy
semantics, and network boundaries are unchanged from `v0.1.0`.

## Marketplace and security readiness

- Uses a unique, truthful root Action name and JPEG-specific description.
- Documents runner-local processing, privacy, support, stable exit codes, and
  the private vulnerability-reporting path.
- Adds weekly Dependabot version checks for pinned Cargo and GitHub Actions
  dependencies.
- Enables repository security controls separately from application policy.

## Release asset

The release includes a macOS Apple Silicon (`aarch64-apple-darwin`) archive and
a sibling SHA-256 file. Linux and other platforms can build from the immutable
tag with the committed `Cargo.lock`.

```text
e8aa1e5fca21fd815457264cb6410355d68d5c1b1548d88aed62bbce544284f2  provenance-ci-v0.1.1-aarch64-apple-darwin.tar.gz
```

## Important limits

Provenance metadata is not a truth, copyright, authorship, AI-detection, or
manipulation oracle. This release supports JPEG only. Remote manifests are not
fetched or evaluated. Trust is checked only when an explicit local PEM snapshot
is supplied. A changed file can be a valid declared derivative; the tool
reports only evidence available at the supplied checkpoints.

This project is not affiliated with or endorsed by C2PA, the Content
Authenticity Initiative, Adobe, or any other vendor. “Provenance CI” is a
working name only.
