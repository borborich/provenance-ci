# Transferability

## Asset contents

- dual-licensed project source;
- pinned dependency graph and notices;
- official/provenanced fixture corpus;
- versioned config/result schemas;
- CLI, Action, sample workflow, release scripts, tests, and documentation;
- future usage/compatibility data only under documented rights.

## Current external services and accounts

None are required to build or run locally. The public source repository is
owned by the `borborich` GitHub account. A future release and Marketplace
listing would use that account unless ownership changes. No domain, cloud,
analytics, payment, email, or monitoring account exists.

## Transfer procedure

1. Transfer the repository/organization access and protect release tags.
2. Transfer or recreate Marketplace publisher ownership and verify whether any
   publisher badge changes.
3. Provide source, all tags, release archives/checksums, `Cargo.lock`, license
   inventory, fixtures/provenance, documentation, issue/advisory history, and
   data-rights schedule.
4. Rotate any future credentials; none exist now.
5. Rebuild from a clean checkout and compare checksums where builds are
   reproducible.
6. Record brand/domain rights separately; the working name has not been
   cleared.

GitHub documents Action repository transfer and listing continuity:
https://docs.github.com/en/actions/how-tos/create-and-publish-actions/publish-in-github-marketplace

## IP and license posture

Project code is `MIT OR Apache-2.0`. Upstream SDK/fixtures retain compatible
licenses. OSS transfer passes license rights, not ownership of upstream code or
vendor trademarks. No C2PA, CAI, Adobe, or Content Credentials brand asset is
bundled.

## Data rights

Current repository contains only official/test fixture data. A future
compatibility dataset must store its test asset provenance, platform/version/
configuration/date, result, and license. User assets and private scans must not
become a saleable dataset without explicit rights.

## Buyer hypotheses, not promises

Potential categories include CDN/image optimization, DAM, CMS, signing/
certificate, media provenance, and CI tooling vendors. No buyer has been
contacted and no valuation is claimed.
