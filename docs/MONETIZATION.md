# Monetization

## Current state

The core CLI and Action are free, local, and unmetered. There is no billing,
paid plan, account, API, or hosted service.

GitHub Actions Marketplace listings do not automatically provide the paid-plan
billing model available to GitHub Apps. Do not promise native Action billing.

## Usage-gated future

Only after repeated third-party use:

- Free: local CLI, Action, public repositories, base checks.
- One paid self-service plan: scheduled hosted monitoring, history, private
  reports, alerts/webhooks, and team policy.

An API or GitHub App is a later distribution/billing surface, not an MVP
requirement. Private repositories must not be paywalled until platform terms
and user value are verified.

## Constraints

- no manual implementation service as the primary product;
- no cold sales;
- no billing before retention;
- no more than one paid plan initially;
- compute cost, support time, inconclusive rate, conversion, MRR, and churn
  must be measured honestly;
- no fabricated installs or revenue.
